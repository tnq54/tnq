# Termux Web Workspace on Hugging Face Spaces

An interactive Linux Web Workspace and Termux terminal environment hosted on Hugging Face Spaces with Streamlit.

## Features
- **Termux Terminal & CLI**: Full command execution with custom `pkg` command emulation and `termux-*` API support.
- **Virtual Extra Keys Bar**: 2-row virtual keys bar for terminal navigation.
- **File Manager & Code Editor**: Browse files, edit code, and manage directory contents.
- **System Dashboard**: Real-time CPU, Memory, Disk, and process monitoring.
- **Custom Themes**: Classic Green, Monokai, Dracula, Solarized Dark, Cyan Cyberpunk.
