# Termux Static Web Interface

Welcome to the **Termux Static Web Workspace** on Hugging Face Spaces.

## Overview
This Space provides an interactive, static web-based Termux terminal environment built directly with HTML5, CSS3, and JavaScript.

## Features
- **Interactive Terminal Shell**: Full command parser supporting Linux/Termux utilities (`ls`, `cd`, `pwd`, `cat`, `echo`, `mkdir`, `touch`, `clear`, `neofetch`, `matrix`, `top`, `theme`, etc.).
- **Termux `pkg` Emulator**: Simulated package management (`pkg install`, `pkg uninstall`, `pkg update`, `pkg search`, `pkg list-installed`).
- **Virtual Extra Keys Bar**: Mobile-friendly virtual key row (`ESC`, `TAB`, `CTRL`, `ALT`, `-`, `/`, `|`, `~`, `▲`, `▼`, `CLEAR`).
- **Color Themes**: Support for `classic`, `monokai`, `dracula`, `solarized`, and `cyan` cyberpunk themes.
- **Matrix Digital Rain**: Built-in HTML5 Canvas Matrix visual animation.
