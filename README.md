# Photoshop CC Web Studio on Hugging Face Spaces

A full-featured Photoshop CC web application running on Hugging Face Spaces with:
- **Photopea / Web Photoshop CC Suite**: Professional PSD editing, full layer manipulation, filters, brush engine, vector masks, and adjustments.
- **HTML5 Canvas Studio**: Light-weight, responsive client-side canvas photo editor.
- **AI Image Suite**: Text-to-Image generation (FLUX.1-dev / SDXL), Gemini 1.5 Flash multimodal photo analysis, and background removal tools.
- **Telegram Bot Integration**: Concurrent background runner for Telegram interactions.
